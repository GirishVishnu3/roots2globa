# Roots2Global - Indian Snacks E-Commerce Platform

A modern, full-featured e-commerce platform for authentic Indian snacks, built with Next.js 14, TypeScript, and MongoDB.

## 🚀 Quick Start

### Development
```bash
npm install
npm run dev
```
Visit `http://localhost:3000`

### Production Build
```bash
npm run build
npm start
```

## 🛠️ Tech Stack

- **Framework:** Next.js 14
- **Language:** TypeScript
- **Database:** MongoDB (Mongoose)
- **Payments:** Stripe
- **Styling:** Tailwind CSS
- **State Management:** Zustand
- **Icons:** Lucide React

## 📦 Features

- ✅ Product catalog with search and filters
- ✅ Shopping cart and wishlist
- ✅ User authentication
- ✅ Stripe payment integration
- ✅ Order management
- ✅ Seller dashboard
- ✅ Multi-currency support with fixed prices (USD, INR, EUR, GBP, CAD, AUD, JPY, AED, SAR)
- ✅ Product discount system (percentage or fixed amount)
- ✅ Responsive design
- ✅ SEO optimized
